Features Array - A feature array is an array that stores the any value (characteristics/variables) of data, which are used for analysis or machine learning on later.

It has 3 types: 

A. For 1 D array only

1. np.zeros(how many rows element) - it store whole array with 0
2. np.ones(how many rows element) - it store whole array with 1
3. np.full(how many element, value what we put) - it store whole array with any specific value

B. For 2 D array only 

1. np.zeros((how many rows, how many columns)) - it store whole array with 0
2. np.ones((how many rows, how many columns)) - it store whole array with 1
3. np.full((how many rows, how many columns), value what we put) - it store whole array with any specific value
